# Anantha Krishna Manivannan — Portfolio

A multi-page dark editorial portfolio for an aspiring software developer and Computer Science & Engineering student at Easwari Engineering College.

## Stack
- HTML5 (Semantic & Accessible)
- CSS3 (Responsive Grid & Flexbox, Dark Editorial Theme)
- Vanilla JavaScript (Responsive navigation, keyboard accessibility)

## Run Locally
Open `index.html` directly in any modern browser, or serve locally with VS Code Live Server / `npx serve`.

## Main Sections
- **Home & About:** Professional profile, perspective, and background.
- **Projects:** Comprehensive case studies of the Vehicle Maintenance Management System, Matrix AI Study App, Smart URL Shortener & Analytics, and Bus Booking System.
- **Experience:** Internships in applied machine learning, backend development, and industry study tours.
- **Achievements:** Hackathons, engineering design sprints, and algorithmic problem solving.
- **Skills & Education:** Academic profile (B.E. CSE, 8.4 CGPA) and categorized technical competencies.
- **Certifications:** Formally verified AWS Certified Cloud Practitioner credential, NPTEL Elite certifications, and specialized badges.
- **Beyond Coding:** Intellectual curiosities, systems thinking, and ethical responsibility.
- **Résumé & Contact:** Direct PDF download, inline document viewer, and contact channels.
