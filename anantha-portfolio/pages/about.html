My Journey

My interest in computer science started with a simple question: what makes software feel effortless to use while remaining rock-solid underneath? Through core coursework in data structures, algorithms, operating systems, and database management, coupled with practical hackathons and software internships, I have continually expanded my technical capabilities from individual scripting to full-scale system architecture.

Core Focus Areas

I focus primarily on full-stack web development with React, Node.js, Express, and PostgreSQL; backend API engineering with Python (FastAPI and Flask); and cloud fundamentals on AWS. I enjoy diving into data pipelines, designing clean database schemas, and integrating AI models into user-facing workflows.

Engineering Philosophy

I believe good software is defined by clarity, restraint, and user empathy. Writing maintainable code requires clean architecture, defensive edge-case handling, and rigorous attention to usability. I treat performance, accessibility, and documentation not as afterthought add-ons, but as core engineering principles from day one.

Future Aspirations

I am actively preparing for software engineering roles where I can contribute to mission-critical systems, collaborate with experienced engineering teams, and build products that deliver meaningful value to users worldwide.
