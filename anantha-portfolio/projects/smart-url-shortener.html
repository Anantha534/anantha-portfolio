Unboxed · Summer Buildfest 2026

Smart URL Shortener & Analytics Platform

A high-performance URL shortening and telemetry tracking engine engineered during a focused six-hour hackathon sprint.

ReactTypeScriptViteTailwind CSSNode.jsExpressSQLitebcrypt

Sprint Context & Objective

Developed as a competitive entry for Unboxed – An Engineering Challenge at Easwari Engineering College (7 August 2026). The competition challenged teams to plan, build, and demonstrate an end-to-end full-stack software application within a strict six-hour time limit.

The goal was to engineer a robust URL-shortening utility that goes beyond simple 301 redirects by collecting actionable click telemetry, device types, and geographic referral patterns without sacrificing redirect latency.

Technical Architecture

  • Base62 Encoding & Hash Collision Management: Implemented a collision-resistant short-slug generator mapping auto-incremented identifiers to compact, human-readable slugs.
  • Telemetry Middleware: Built lightweight Express request middleware that parses User-Agent headers, IP origins, and HTTP referrers asynchronously so redirect responses remain instantaneous.
  • Embedded Persistence: Configured SQLite with WAL (Write-Ahead Logging) mode to handle concurrent link generation and high-volume redirect hits with zero external database overhead.
  • Client Dashboard: Crafted a clean React and TypeScript interface using Vite, allowing users to create custom vanity aliases, view real-time click volume counters, and inspect breakdown charts.

Key Features

  • Instant Link Shortening: Generates concise, shareable redirect links from arbitrary-length URLs.
  • Custom Vanity Aliases: Allows users to specify branded or memorable URL slugs.
  • Click Telemetry: Logs timestamps, referrers, and browser information on each incoming redirect hit.
  • Analytics Summary: Visual displays of top traffic sources and access timeline graphs.

Technology Stack

React · TypeScript · Vite · Tailwind CSS · Node.js · Express · SQLite · bcrypt

Engineering Decisions & Outcomes

Building under strict hackathon constraints enforced disciplined technical choices: prioritizing reliable, file-backed SQLite persistence over heavy microservice topologies, maintaining strict TypeScript typing across the client and server interfaces, and decoupling redirect execution from analytical database writes.

The resulting prototype achieved fast link redirection and provided an intuitive telemetry dashboard, successfully completing all sprint requirements.
